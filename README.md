### ⚡ What I'm up to right now

- 🧙‍♂️ **Backend & Black Magic:** Taming legacy SOAP/XML systems (TOTVS/Fluig) with clean NestJS middleware. I build the API bridges and wrap them in custom, metadata-driven RBAC engines from scratch to keep everything secure and my sanity intact.
- 🎨 **Frontend (The Hard Way):** Building PWAs and state-aware routers using pure Vanilla JS. No frameworks, no `node_modules` black holes, no overhead, no excuses.
